Uninstall

One command for your platform, or remove it manually.

curl -fsSL https://depradar-app.github.io/depradar/uninstall.sh | sh
irm https://depradar-app.github.io/depradar/uninstall.ps1 | iex

macOS

brew uninstall --cask depradar-app/tap/depradar
Installed by dragging the .dmg instead? Move DepRadar.app to the Trash.

Debian / Ubuntu

sudo apt remove depradar

Linux (AppImage)

rm ~/.local/bin/depradar
(or wherever you placed the AppImage file — it's portable, nothing else to clean up)

Windows

Settings → Apps → DepRadar → Uninstall
